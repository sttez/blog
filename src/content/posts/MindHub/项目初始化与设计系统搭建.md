# 项目初始化与设计系统搭建

## 为什么是 Next.js 16 + shadcn/ui

5 月 5 日上午，我坐在电脑前，决定用两天时间做一个 AI 驱动的知识工作台——MindHub。技术选型其实没什么纠结的：

- **Next.js App Router**：成熟的全栈框架，静态导出也方便
- **shadcn/ui**：不是组件库，是"可复制的组件代码"，完全可控
- **Tailwind CSS v4**：原子化 CSS，和 shadcn/ui 天然搭配
- **TypeScript**：没什么好说的，必选

初始化项目：

```bash
npx create-next-app@latest mindhub --typescript --tailwind --eslint --app --src-dir
cd mindhub
npx shadcn@latest init
```

shadcn 初始化后，我一口气装了 11 个组件：

```bash
npx shadcn@latest add button card dialog input select textarea tabs badge separator scroll-area dropdown-menu tooltip
```

## 设计系统：从 DESIGN.md 到 globals.css

我先写了一份 DESIGN.md 定义设计规范，然后把它映射到 CSS 变量里。核心决策：

- **主色调**：Deep Navy `#000000`，极简主义风格
- **字体**：Manrope（标题）+ Inter（正文），通过 `next/font` 加载
- **间距**：8px 网格系统，所有间距都是 8 的倍数
- **风格**：Minimalism + Corporate Modern

globals.css 里的关键变量：

```css
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 222.2 47.4% 11.2%;
  --radius: 0.75rem;
}

@theme inline {
  --font-sans: 'Inter', sans-serif;
  --font-heading: 'Manrope', sans-serif;
}
```

## 全局布局：Sidebar + TopBar

应用采用经典的侧边栏 + 顶部导航布局。`layout.tsx` 的结构：

```
<SidebarProvider>
  <AppSidebar />
  <main>
    <TopBar />
    {children}
  </main>
</SidebarProviderProvider>
```

Sidebar 用 shadcn/ui 的 `Sheet` 组件做移动端适配，TopBar 包含搜索框、主题切换和用户头像。

## Mock 数据层

在没有后端的情况下，我写了一个 `mock.ts`，包含所有资源、任务流、知识图谱的假数据。这让前端可以完全独立开发，不用等后端 API。事实证明这个决策非常正确——它让第二天的页面开发效率极高。

## 小结

上午的几个小时，完成了从零到一个有设计系统、有布局、有 11 个 UI 组件、有 mock 数据的项目骨架。下午就可以全力冲页面了。
