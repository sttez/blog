# 核心页面从零到一

## 资源工作台：Bento Grid 卡片

MindHub 的首页是资源工作台，核心是一个 Bento Grid 布局的卡片网格。每张资源卡片有两个关键区域：

- **封面区**：根据资源类型显示不同的视觉元素（视频缩略图、文章预览、链接图标等）
- **AI 摘要区**：展示 AI 生成的内容摘要，带标签和分类

Bento Grid 的实现用了 CSS Grid，关键在于不规则排列：

```tsx
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4 auto-rows-[200px]">
  {resources.map((resource) => (
    <ResourceCard
      key={resource.id}
      resource={resource}
      className={resource.featured ? "md:col-span-2 md:row-span-2" : ""}
    />
  ))}
</div>
```

featured 资源占更大的格子，普通资源占单格，视觉上形成错落感。

## 七个页面，一下午

5 号下午我一口气搭了 7 个页面。有了 mock 数据和 shadcn/ui 组件，速度非常快：

| 页面 | 路由 | 核心内容 |
|------|------|----------|
| 资源工作台 | `/` | Bento Grid 卡片网格 |
| 资源查看器 | `/viewer` | 视频/文章阅读详情 |
| 任务流 | `/flows` | 流程编排画布 |
| 知识图谱 | `/graph` | 图谱可视化 |
| 洞察分析 | `/insight` | AI 驱动的分析面板 |
| 历史记录 | `/history` | 操作时间线 |
| 归档中心 | `/archive` | 已归档资源管理 |

## 洞察分析页

Insight 页面的设计思路是"AI 分析结果的仪表盘"。顶部是分析维度选择器（时间、分类、关键词），下方是 AI 生成的洞察卡片和趋势图表。这个阶段还是纯 mock 数据，图表用的占位元素。

## 知识图谱页

Graph 页面初步搭了一个图谱容器，节点和边的数据结构已经定义好，但可视化部分当时还比较粗糙——后来在第二轮迭代中用 Cytoscape.js 做了完整重写。

## 历史记录与归档

这两个页面相对简单。History 页面是一个时间线组件，按日期分组展示操作记录。Archive 页面是资源列表的变体，多了"恢复"和"永久删除"操作。

## 全面中文化

所有页面搭完后，我做了一轮全面的中文本地化。把所有硬编码的英文 UI 文本替换成中文，同时增强了各页面的交互细节——悬停效果、加载状态、空状态提示等。

## 小结

一个下午，7 个页面从零到一。关键心得：mock 数据先行 + 高质量组件库 = 极速原型开发。页面虽然还是"壳"，但交互和视觉已经很接近最终效果了。
