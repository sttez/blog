# 从零训练一个微表情识别模型

## 环境准备

### 第一步：创建 conda 环境

```bash
conda create -n micro-expression python=3.10
conda activate micro-expression
```

### 第二步：安装依赖

dlib 需要用 conda 安装（pip 容易失败），其余用 pip：

```bash
conda install -c conda-forge dlib
pip install torch torchvision opencv-python numpy pandas scikit-learn
pip install matplotlib seaborn tqdm pillow gradio PyQt5
```

### 第三步：下载资源文件

项目需要两个预训练文件放在 `utils/` 目录下：

- `haarcascade_frontalface_default.xml`：OpenCV 人脸检测 cascade
- `shape_predictor_68_face_landmarks.dat`：dlib 68 点形状预测器

## 数据准备

### 下载 CASME2 数据集

CASME2 是学术数据集，需要从中科院自动化所申请。下载后解压到 `data/CASME2-RAW/` 目录，结构如下：

```
data/
├── CASME2-RAW/
│   ├── sub01/
│   │   ├── EP02_01/
│   │   │   ├── 001.jpg
│   │   │   └── ...
│   │   └── ...
│   └── sub26/
└── CASME2-coding-20140508.xlsx
```

### 运行预处理

```bash
cd data
python prepare_dataset.py
```

这一步会：
1. 分析类别分布，排除样本不足的 fear 和 sadness
2. 逐帧提取人脸、68 点关键点、Farneback 光流
3. 构建 32 帧定长序列，每个类别至少 475 个样本
4. 水平翻转做数据增强
5. 按 8:2 分层分割训练/测试集

预处理首次运行需要几个小时（主要耗时在光流计算），之后会缓存中间结果。

## 模型训练

### 快速验证（可选）

先用少量数据跑 5 个 epoch，确认流程没问题：

```bash
python training/quick_test.py
```

### 标准训练

```bash
python training/trainer.py
```

默认配置（`config.ini`）：
- batch_size = 8
- num_epochs = 30
- learning_rate = 0.0001
- early_stopping_patience = 10

训练过程中每 5 个 epoch 自动保存 loss 曲线和准确率曲线。

### 分阶段训练（推荐）

在 `config.ini` 中设置 `stage = 1`，先训练 CNN 特征提取器：

```bash
python training/trainer.py
```

训练完成后记录 checkpoint 路径，设置 `stage = 2` 和 `stage1_checkpoint`，联合微调：

```ini
[training]
stage = 2
stage1_checkpoint = models/weights/xxx/stage1_best.pth
```

```bash
python training/trainer.py
```

## 使用训练好的模型

### 桌面应用

```bash
python main.py
```

在 Tkinter 启动器中选择"桌面应用"，通过菜单栏"模型→切换模型"选择训练好的模型。

### Web 界面

```bash
python interfaces/webapp/gradio_app.py
```

浏览器打开 `http://127.0.0.1:7860` 即可使用。

## 常见问题

**Q：训练时 loss 不下降？**
A：检查学习率是否太大，尝试降低到 0.00001。也可能是数据预处理有问题，检查 `cls_train.txt` 格式。

**Q：准确率很低？**
A：微表情本身就是难题，CASME2 上 5 类分类 70-80% 的准确率已经不错了。试试分阶段训练。

**Q：显存不够？**
A：降低 batch_size（到 4 或 2），或者减少 sequence_length（到 16）。
