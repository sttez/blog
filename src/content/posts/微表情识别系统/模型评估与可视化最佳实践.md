# 模型评估与可视化最佳实践

## 为什么需要可视化

训练日志里的数字刷屏太快，光看 `loss=0.342 acc=0.876` 很难判断模型状态。把训练过程画成图表，一眼就能看出问题。

## 训练曲线

`training/metrics.py` 实现了三种核心曲线的绘制：

### Loss 曲线

```python
def plot_loss_curve(history, save_dir):
    epochs = range(1, len(history['train_losses']) + 1)
    plt.plot(epochs, history['train_losses'], 'b-', label='Train Loss')
    plt.plot(epochs, history['val_losses'], 'r-', label='Val Loss')
    plt.xlabel('Epoch')
    plt.ylabel('Loss')
    plt.legend()
    plt.savefig(os.path.join(save_dir, 'loss_curve.png'))
```

关键观察点：
- train loss 持续下降、val loss 也下降 = 正常学习
- train loss 下降但 val loss 上升 = 过拟合，需要 early stopping
- 两者都不下降 = 学习率太大或者模型容量不够

### 准确率曲线

train acc 和 val acc 的差距反映泛化能力。理想情况下两者差距在 5% 以内。

### F1 曲线

微表情数据集类别不平衡，accuracy 可能不靠谱。F1（加权平均）更全面地反映模型在各类别上的表现。

## 混淆矩阵

测试集评估后生成混淆矩阵，直观显示哪些类别容易搞混：

```python
from sklearn.metrics import confusion_matrix
import seaborn as sns

def plot_confusion_matrix(y_true, y_pred, labels, save_dir):
    cm = confusion_matrix(y_true, y_pred)
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
                xticklabels=labels, yticklabels=labels)
    plt.xlabel('Predicted')
    plt.ylabel('True')
    plt.savefig(os.path.join(save_dir, 'confusion_matrix.png'))
```

常见问题的判断：
- 某一列数据很分散 = 该类别容易被误判为其他类别
- 两类之间互相对称误判 = 这两个类别特征太相似
- 对角线上有明显的深色格 = 该类别识别率高

## 分类报告

sklearn 的 `classification_report` 提供每个类别的精确率、召回率和 F1：

```python
from sklearn.metrics import classification_report

report = classification_report(y_true, y_pred, target_names=labels)
print(report)
```

输出示例：

## 自动保存结果

训练结束后，所有指标保存为 JSON，方便后续分析：

```python
results = {
    'best_val_accuracy': best_acc,
    'test_accuracy': test_acc * 100,
    'test_f1_score': test_f1,
    'classification_report': report,
    'config': {...}
}
with open('results.json', 'w') as f:
    json.dump(results, f, indent=4, default=str)
```

模型文件夹的命名也包含准确率：`MicroExpModel_20260508_143022_82.35`，一眼就能看出效果。

## 实用建议

- 每 5 个 epoch 画一次图就够了，太频繁浪费时间
- 关注 val 指标比 train 指标更重要
- 混淆矩阵是发现类别混淆问题的最佳工具
- F1 比 accuracy 更适合类别不平衡的场景
