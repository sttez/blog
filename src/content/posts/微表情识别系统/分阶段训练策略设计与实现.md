# 分阶段训练策略设计与实现

## 问题背景

CASME2 数据集很小——排除掉样本不足的类别后，总共也就几千个序列样本。直接端到端训练 300 万参数的三流模型，很容易过拟合或者迟迟不收敛。

参考计算机视觉中 fine-tune 的常见做法，我设计了一个分阶段训练策略。

## 三种训练模式

在 `config.ini` 里通过 `stage` 参数控制：

| stage | 模式 | 行为 |
|-------|------|------|
| 0 | 标准训练 | 所有参数一起训练，适合数据量充足的情况 |
| 1 | CNN 特征提取 | 冻结 LSTM+Classifier，只训练三个特征提取器 |
| 2 | 联合微调 | 加载阶段 1 权重，解冻全部，以较低学习率联合训练 |

## 实现细节

### 阶段 1：冻结主干

核心逻辑在 `freeze_backbone` 函数：

```python
def freeze_backbone(model):
    for name, param in model.named_parameters():
        if 'lstm' not in name and 'classifier' not in name:
            param.requires_grad = False
```

只保留 LSTM 和 Classifier 的梯度，CNN 和 FC 特征提取器被冻结。此时用较高的学习率（0.001）训练 25 个 epoch，让分类头先学会利用特征。

### 阶段 2：联合微调

```python
# 加载阶段 1 权重
checkpoint = torch.load(stage1_ckpt)
model.load_state_dict(checkpoint['model_state_dict'])

# 解冻全部参数
unfreeze_all(model)

# 用较低学习率训练
optimizer = optim.Adam(model.parameters(), lr=0.0001)
```

关键点：阶段 2 的学习率（0.0001）是阶段 1（0.001）的十分之一。因为预训练的特征提取器只需要微调，太大的学习率会破坏已学到的特征。

### Early Stopping 与学习率调度

两阶段都用相同的训练循环，包含 early stopping 和 ReduceLROnPlateau：

```python
scheduler = optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, mode='min', factor=0.5, patience=3, min_lr=1e-6
)

# 在每个 epoch 后
if val_acc > best_val_acc:
    best_val_acc = val_acc
    patience_counter = 0
    torch.save(model.state_dict(), 'best_model.pth')
else:
    patience_counter += 1

if patience_counter >= patience:  # 默认 10
    break
```

## 训练过程可视化

每 5 个 epoch 自动保存训练曲线：

- **Loss 曲线**：train loss 和 val loss 的变化趋势
- **准确率曲线**：train acc 和 val acc 的对比
- **F1 曲线**：加权 F1 分数变化
- **混淆矩阵**：最终测试集的分类结果

## 配置参考

```ini
[training]

stage1_learning_rate = 0.001
stage1_epochs = 25
learning_rate = 0.0001
num_epochs = 30
early_stopping_patience = 10
train_split = 0.8
batch_size = 8
```

## 实际效果

分阶段训练确实比直接端到端训练更稳定。阶段 1 让 CNN 学会提取面部特征，阶段 2 在此基础上做端到端微调。在 CASME2 上，分阶段训练的最终准确率比标准训练高了几个百分点，而且收敛更快、曲线更平滑。

对于小数据集的多流网络，分阶段训练是一个简单有效的技巧——不需要改模型结构，只改训练策略就能提升效果。
