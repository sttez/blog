# 模型从 68M 到 3M 的参数压缩之路

## 问题

原版微表情识别模型有 6800 万参数。对于 CASME2 这种只有几千个样本的小数据集，参数量严重过剩，训练时：

- 收敛慢，30 个 epoch 还在震荡
- 容易过拟合，train acc 很高但 val acc 上不去
- 模型文件巨大，加载和推理都慢

## 参数量去哪了

用 PyTorch 逐层统计参数后，发现 68M 里的绝大部分都集中在 CNN 到 LSTM 的连接层：

| 层 | 原版参数量 | 说明 |
|----|-----------|------|
| image_cnn | ~32K | 卷积层本身参数不多 |
| flatten→fc | ~32M | **128×16×16=32768 维 flatten 后接全连接，参数爆炸** |
| flow_cnn | ~32K | 同上 |
| flatten→fc | ~32M | **同样问题** |
| lstm | ~2M | LSTM 参数量正常 |
| classifier | ~83K | 分类头参数很少 |

罪魁祸首是 flatten + 全连接：CNN 输出是 128×16×16=32768 维，直接 flatten 后接全连接层，光这两层就占了 64M 参数。

## 解决方案：GAP

全局平均池化（Global Average Pooling）把每个 16×16 的特征图压缩成一个值：

```python
# 原版：flatten + FC（32M 参数）
self.flatten = nn.Flatten()
self.fc = nn.Linear(128 * 16 * 16, 256)

# 优化版：GAP（0 参数）
self.pool = nn.AdaptiveAvgPool2d(1)  # (B, 128, 16, 16) → (B, 128, 1, 1)
```

一个 `AdaptiveAvgPool2d(1)` 就干掉了 32M 参数，而且零学习成本——它没有可训练参数，只是简单地对每个特征图求平均。

## 同时加 BatchNorm

顺便在每个 Conv 层后面加了 BatchNorm：

```python
nn.Sequential(
    nn.Conv2d(1, 32, 3, padding=1),
    nn.BatchNorm2d(32),    # 新增
    nn.ReLU(),
    nn.MaxPool2d(2),
    ...
)
```

BatchNorm 本身参数很少（每个通道只有两个参数：scale 和 bias），但能让训练更稳定、收敛更快。

## 优化结果

| 指标 | 原版 | 优化版 |
|------|------|--------|
| 总参数量 | 68M | 3M |
| 模型大小 | ~260MB | ~12MB |
| 收敛速度 | 30 epoch 不稳定 | ~20 epoch 收敛 |
| 识别准确率 | 基线 | 基本持平 |

参数量减少了 95%，但准确率没有明显下降。这说明原版模型的大量参数都是冗余的——CNN 特征本来只需要 128 维，非要展开到 32768 维再压缩回来，纯属浪费。

## 学到的教训

**小数据集上的大模型不一定是好事。** 参数量和数据量要匹配，CASME2 只有几千个样本，3M 参数的模型已经足够表达能力了。68M 参数在这么小的数据集上只会过拟合。

另外，GAP 是一个被低估的技巧。它不仅减少参数量，还能起到正则化的作用——每个特征图只有一个输出值，模型被迫学出更有判别力的特征。
