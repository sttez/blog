# 微信小程序项目初始化

## 立项：二次元社区小程序

次元聚是一个面向二次元爱好者的微信小程序社区，核心功能包括动态发布、约单交易、实时聊天、教程分享和个人资料管理。技术选型上，前端用微信小程序原生开发，后端 Node.js + Express + MySQL。

选原生小程序而不是 Taro 或 uni-app，原因很简单：项目体量不大，原生开发调试最方便，微信开发者工具的体验也足够好。

```

│   ├── services/       # 业务逻辑

└── seed.js             # 测试数据脚本

sql/
├── schema.sql          # 数据库架构

```

## 后端初始化

Express 服务器搭了一个最简骨架：

```javascript
const express = require('express');
const http = require('http');
const { Server } = require('socket.io');
const mysql = require('mysql2/promise');

const app = express();
const server = http.createServer(app);
const io = new Server(server, { cors: { origin: '*' } });

app.use(express.json());

// 连接池
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  database: 'ciyuanju',
  connectionLimit: 20
});

server.listen(3000, () => console.log('Server running on port 3000'));
```

Socket.IO 从一开始就被纳入方案，因为实时聊天是核心需求之一。

## 小结

项目骨架搭建花了一个下午。核心决策：原生小程序 + Express + MySQL + Socket.IO，不引入多余框架，保持简洁。后续每个页面独立开发，通过 tabBar 导航串联。
