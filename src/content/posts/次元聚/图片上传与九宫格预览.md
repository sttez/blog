# 图片上传与九宫格预览

## 需求

首页和教程页面都支持发布内容时上传图片，最多 9 张。上传后需要在页面上预览，支持删除已选图片，布局采用 3 列网格（九宫格）。

## 实现方案

用微信小程序原生的 `wx.chooseImage` API 选图，选完后把临时路径存入 `data.images` 数组，页面通过 `wx:for` 渲染预览网格。

```javascript
chooseImage() {
  const remaining = 9 - this.data.images.length;
  if (remaining <= 0) {
    wx.showToast({ title: '最多上传9张', icon: 'none' });
    return;
  }

  wx.chooseImage({
    count: remaining,
    sizeType: ['compressed'],
    sourceType: ['album', 'camera'],
    success: (res) => {
      this.setData({
        images: [...this.data.images, ...res.tempFilePaths]
      });
    }
  });
}
```

`count` 参数设为 `remaining`，确保不会超过 9 张上限。`sizeType` 选 `compressed`，自动压缩减少上传体积。

## 九宫格布局

WXML 中用 3 列 CSS Grid 实现：

```html
<view class="image-grid">
  <view class="image-item" wx:for="{{images}}" wx:key="*this">
    <image src="{{item}}" mode="aspectFill" />
    <view class="remove-btn" bindtap="removeImage" data-index="{{index}}">
      <image src="/icons/close.png" />
    </view>
  </view>
  <view class="image-item add-btn" wx:if="{{images.length < 9}}" bindtap="chooseImage">
    <image src="/icons/plus.png" />
  </view>
</view>
```

## 删除图片

点击每张图片右上角的关闭按钮，通过 `data-index` 定位要删除的图片：

```javascript
removeImage(e) {
  const index = e.currentTarget.dataset.index;
  const images = [...this.data.images];
  images.splice(index, 1);
  this.setData({ images });
}
```

## 提交时的处理

发布时，图片临时路径数组通过 JSON 序列化存入数据库。后端接收后存入 `posts` 表的 `images` JSON 列：

```javascript
submitPost() {
  wx.request({
    url: 'http://localhost:3000/api/posts',
    method: 'POST',
    data: {
      user_id: getApp().globalData.userId,
      title: this.data.title,
      content: this.data.content,
      images: this.data.images,
      category: this.data.activeCategory
    },
    success: () => {
      wx.showToast({ title: '发布成功' });
      this.setData({ showPublishModal: false, images: [], title: '', content: '' });
    }
  });
}
```

实际生产环境应该把图片上传到云存储（如腾讯云 COS），返回 URL 后再存入数据库。目前项目先用临时路径做开发验证。

## 小结

图片上传功能的核心：`wx.chooseImage` 选图 → 数组存储路径 → Grid 布局预览 → 序列化存库。整个实现约 100 行代码，没有引入任何第三方库。九宫格的 add 按钮在图片数小于 9 时显示，满了自动隐藏，交互很自然。
