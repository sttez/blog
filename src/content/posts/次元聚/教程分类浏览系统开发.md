# 教程分类浏览系统开发

## 三级页面结构

教程功能有三个层级页面：

1. **教程首页**（`tutorial`）→ 6 个分类的网格入口
2. **课程列表**（`tutorial-list`）→ 某分类下的所有课程
3. **课程详情**（`tutorial-detail`）→ 单个课程的完整内容

## 分类网格

教程首页是一个 2 列 × 3 行的网格，每个格子代表一个分类：

```html
<view class="category-grid">
  <view
    class="grid-item"
    wx:for="{{categories}}"
    wx:key="id"
    bindtap="goToList"
    data-id="{{item.id}}"
    data-name="{{item.name}}"
    style="animation-delay: {{index * 0.08}}s"
  >
    <image class="grid-icon" src="{{item.icon}}" />
    <text class="grid-name">{{item.name}}</text>
    <text class="grid-count">{{item.count}} 课程</text>
  </view>
</view>
```

```css
.category-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 20rpx;
  padding: 24rpx;
}

.grid-item {
  background: #FFFFFF;
  border-radius: 20rpx;
  padding: 32rpx 24rpx;
  display: flex;
  flex-direction: column;
  align-items: center;
  box-shadow: 0 4rpx 12rpx rgba(157, 122, 255, 0.08);
  animation: staggeredBounce 0.4s ease both;
}
```

六个分类：COS、摄影、妆造、发型、色彩、视频。`animation-delay` 实现网格项依次入场的弹跳效果。

## 课程列表页

点击分类格子跳转到列表页，URL 带分类 ID 和名称：

```javascript
goToList(e) {
  const { id, name } = e.currentTarget.dataset;
  wx.navigateTo({
    url: `../tutorial-list/tutorial-list?id=${id}&name=${name}`
  });
}
```

列表页在 `onLoad` 中请求该分类下的课程：

```javascript
onLoad(options) {
  this.setData({ categoryName: options.name });
  wx.setNavigationBarTitle({ title: options.name });
  wx.request({
    url: `http://localhost:3000/api/tutorials?category=${options.id}`,
    success: (res) => {
      this.setData({ courses: res.data });
    }
  });
}
```

列表每项展示课程编号、标题、作者和时间：

```html
<view class="course-item" wx:for="{{courses}}" wx:key="id" bindtap="goToDetail" data-id="{{item.id}}">
  <text class="course-num">#{{index + 1}}</text>
  <view class="course-info">
    <text class="course-title">{{item.title}}</text>
    <view class="course-meta">
      <text>{{item.author_name}}</text>
      <text>{{item.created_at}}</text>
    </view>
  </view>
</view>
```

## 课程详情页

详情页展示完整的课程内容，包括作者卡片、正文、图片集、统计信息和操作栏：

```html
<view class="detail-page">
  <!-- 作者卡片 -->
  <view class="author-card">
    <image class="author-avatar" src="{{course.author_avatar}}" />
    <view class="author-info">
      <text class="author-name">{{course.author_name}}</text>
      <text class="author-role">{{course.author_role}}</text>
    </view>
    <view class="follow-btn">关注</view>
  </view>

  <!-- 正文 -->
  <text class="course-content">{{course.content}}</text>

  <!-- 图片集 -->
  <view class="image-gallery" wx:if="{{course.images.length > 0}}">
    <image
      wx:for="{{course.images}}"
      wx:key="*this"
      src="{{item}}"
      mode="widthFix"
      bindtap="previewImage"
      data-src="{{item}}"
    />
  </view>

  <!-- 统计栏 -->
  <view class="stats-bar">
    <text>{{course.views}} 浏览</text>
    <text>{{course.likes}} 点赞</text>
    <text>{{course.comments}} 评论</text>
  </view>

  <!-- 操作栏 -->
  <view class="action-bar">
    <view class="action-item" bindtap="toggleLike">
      <image src="{{liked ? '/icons/liked.png' : '/icons/like.png'}}" />
      <text>点赞</text>
    </view>
    <view class="action-item" bindtap="goToComment">
      <image src="/icons/comment.png" />
      <text>评论</text>
    </view>
    <view class="action-item" bindtap="shareTutorial">
      <image src="/icons/share.png" />
      <text>分享</text>
    </view>
  </view>
</view>
```

## 发布教程

教程首页右上角有"发布"按钮，弹出发布模态框。和首页动态发布类似，但增加了分类选择器：

```html
<view class="publish-modal" wx:if="{{showPublishModal}}">
  <input placeholder="教程标题" value="{{pubTitle}}" />
  <picker mode="selector" range="{{categoryNames}}" bindchange="onCategoryPick">
    <view class="picker-item">{{pubCategory || '选择分类'}}</view>
  </picker>
  <textarea placeholder="教程内容" value="{{pubContent}}" />
  <!-- 图片网格同首页 -->
  <view class="submit-btn" bindtap="submitTutorial">发布</view>
</view>
```

## 小结

教程系统的三级页面（首页 → 列表 → 详情）是一个经典的导航模式。核心要点：分类网格用 CSS Grid + staggered animation 做入场效果，列表页通过 URL 参数决定加载哪类数据，详情页是内容展示的终点页面。整个教程系统约 500 行代码。
