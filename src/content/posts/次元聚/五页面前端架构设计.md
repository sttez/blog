# 五页面前端架构设计

## 页面规划

次元聚的五个核心页面各司其职：

| 页面 | 路径 | 核心职责 |
|------|------|----------|
| 首页 | `pages/home/` | 动态浏览、发布、分类筛选 |
| 约单 | `pages/trading/` | 订单列表、详情、支付流程 |
| 消息 | `pages/messaging/` | 会话列表、实时聊天 |
| 教程 | `pages/tutorial/` | 分类网格、课程列表、详情 |
| 我的 | `pages/myprofile/` | 个人资料、登录状态管理 |

每个页面由三个文件组成：`.wxml`（模板）、`.wxss`（样式）、.js（逻辑）。某些页面有子页面，比如约单下面有 `trading-detail`、`trading-payment`、`trading-success` 三个子页面。

## 数据流设计

小程序的数据流遵循微信官方的 `setData` 模式：

```javascript
Page({
  data: {
    posts: [],
    loading: true,
    activeCategory: 'all'
  },

  onLoad() {
    this.loadPosts();
  },

  loadPosts() {
    wx.request({
      url: 'http://localhost:3000/api/posts',
      success: (res) => {
        this.setData({ posts: res.data, loading: false });
      }
    });
  }
})
```

每个页面在 `onLoad` 生命周期中发起 API 请求，通过 `setData` 更新视图。没有引入额外的状态管理库，小程序本身的 Page 模式已经够用。

## 首页：分类导航 + 动态列表

首页分两部分：顶部是 8 个分类的水平滚动导航栏（全部/COS/摄影/妆造/发型/道具/教程/闲聊），下面是动态信息流。

分类导航用 `scroll-view` 实现横向滚动：

```html
<scroll-view class="category-bar" scroll-x>
  <view
    wx:for="{{categories}}"
    wx:key="id"
    class="category-item {{activeCategory === item.id ? 'active' : ''}}"
    bindtap="switchCategory"
    data-id="{{item.id}}"
  >
    {{item.name}}
  </view>
</scroll-view>
```

## 约单：三页面流程

约单不是单个页面，而是一个三步流程：

1. **订单列表**（`trading`）→ 浏览所有订单
2. **订单详情**（`trading-detail`）→ 查看发布者信息和需求
3. **支付确认**（`trading-payment`）→ 选择支付方式
4. **支付成功**（`trading-success`）→ 结果展示

页面间通过 URL 参数传递订单 ID 和价格：

```javascript
goToPayment(e) {
  const { id, price } = e.currentTarget.dataset;
  wx.navigateTo({
    url: `../trading-payment/trading-payment?id=${id}&price=${price}`
  });
}
```

## 消息：会话 + 聊天面板

消息页面比较特殊，它在一个页面内切换两个视图：会话列表和聊天面板。通过 `data.currentView` 控制显示哪个视图：

```html
<view wx:if="{{currentView === 'conversations'}}">
  <!-- 会话列表 -->
</view>
<view wx:elif="{{currentView === 'chat'}}">
  <!-- 聊天面板 -->
</view>
```

## 我的：登录态判断

MyProfile 页面的核心是登录状态切换。`onLoad` 时检查本地存储的登录态，用 `isLoggedIn` 数据字段控制渲染：

```html
<view wx:if="{{isLoggedIn}}">
  <!-- 已登录界面：个人信息、统计、作品集 -->
</view>
<view wx:else>
  <!-- 未登录界面：头像 + 登录按钮 -->
</view>
```

## 小结

五页面的架构核心思路：每个页面职责单一，页面间通过 tabBar 导航，子页面通过 `navigateTo` 串联。数据全靠 `setData` 驱动，没有额外状态管理。简单的架构反而让后续开发和调试都很清晰。
