# 紫蓝色设计系统搭建

## 二次元风格的色彩选择

次元聚的目标用户是二次元爱好者，设计语言需要活泼但不幼稚。主色选了紫色系——`#9D7AFF` 作为主色，`#7C5CE6` 作为深色变体。紫色在二次元文化中辨识度高，又不会像粉色那样过于可爱。

辅助色用 `#00D4FF`（亮蓝）和 `#FF6FB1`（粉），分别用于强调和点缀。背景色 `#F9F7FF` 是一个极浅的紫灰，比纯白更有层次感。

## 色彩系统

```css
/* 全局颜色变量 */
:root {
  --primary: #9D7AFF;
  --primary-dark: #7C5CE6;
  --accent-blue: #00D4FF;
  --accent-pink: #FF6FB1;
  --accent-orange: #FFB84D;
  --text-primary: #1A1428;
  --text-secondary: #666666;
  --bg-main: #F9F7FF;
  --bg-card: #FFFFFF;
  --border-color: #E8E0F0;
}
```

## 字体与间距

标题用系统默认的中等粗细字体，正文用常规粗细。间距遵循 4 的倍数规则——`8rpx`、`16rpx`、`24rpx`、`32rpx`。小程序里用 `rpx` 做响应式适配，不同屏幕宽度下自动缩放。

## 动画体系

设计了四套核心动画：

```css
/* 模态框从底部滑入 */
@keyframes slideUp {
  from { transform: translateY(100%); opacity: 0; }
  to { transform: translateY(0); opacity: 1; }
}

/* 按钮点击缩放反馈 */
.button:active {
  transform: scale(0.96);
  transition: transform 0.1s ease;
}

/* 网格项依次入场 */
@keyframes staggeredBounce {
  0% { opacity: 0; transform: translateY(20px); }
  100% { opacity: 1; transform: translateY(0); }
}

/* 成功图标脉冲 */
@keyframes pulse {
  0% { transform: scale(0.8); opacity: 0; }
  50% { transform: scale(1.1); }
  100% { transform: scale(1); opacity: 1; }
}
```

slideUp 用在所有模态框上，0.3s ease-out 的时长让弹出感很自然。staggeredBounce 配合 `animation-delay` 实现列表项的依次入场效果。

## 组件样式规范

### 卡片

```css
.card {
  background: #FFFFFF;
  border: 1rpx solid #E8E0F0;
  border-radius: 16rpx;
  box-shadow: 0 2rpx 8rpx rgba(157, 122, 255, 0.08);
  padding: 24rpx;
}
```

卡片加了一层极淡的紫色阴影，而不是通用的灰色阴影，整体色调更统一。

### 按钮

主按钮用渐变背景 `linear-gradient(135deg, #9D7AFF, #7C5CE6)`，文字白色。次按钮用描边样式。所有按钮都有 `active` 状态的缩放反馈。

## 小结

设计系统的搭建花了一天，但为后续所有页面开发提供了统一规范。核心原则：紫色为主、4rpx 倍数间距、四种动画覆盖所有交互场景。后续页面开发不再需要纠结颜色和间距，直接引用变量即可。
