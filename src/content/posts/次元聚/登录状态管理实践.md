# 登录状态管理实践

## 需求

"我的"页面需要根据登录状态显示不同界面：未登录时显示大头像和登录按钮，已登录时显示个人资料、统计数据、作品集和菜单项。

## 登录态检测

用微信小程序的本地存储做登录态持久化。`onLoad` 时检查 `userInfo` 是否存在：

```javascript
Page({
  data: {
    isLoggedIn: false,
    userInfo: null,
    stats: { works: 0, followers: 0, following: 0 }
  },

  onLoad() {
    const userInfo = wx.getStorageSync('userInfo');
    if (userInfo) {
      this.setData({
        isLoggedIn: true,
        userInfo: userInfo
      });
      this.loadStats();
    }
  },

  loadStats() {
    wx.request({
      url: `http://localhost:3000/api/users/${this.data.userInfo.id}/stats`,
      success: (res) => {
        this.setData({ stats: res.data });
      }
    });
  }
})
```

## 双界面切换

WXML 用 `wx:if` 控制两个完全不同的界面：

```html
<!-- 已登录界面 -->
<view wx:if="{{isLoggedIn}}" class="profile-page">
  <view class="profile-header">
    <image class="avatar" src="{{userInfo.avatar}}" />
    <text class="nickname">{{userInfo.nickname}}</text>
    <text class="role-tag">{{userInfo.role}}</text>
  </view>

  <view class="stats-bar">
    <view class="stat-item">
      <text class="stat-num">{{stats.works}}</text>
      <text class="stat-label">作品</text>
    </view>
    <view class="stat-item">
      <text class="stat-num">{{stats.followers}}</text>
      <text class="stat-label">粉丝</text>
    </view>
    <view class="stat-item">
      <text class="stat-num">{{stats.following}}</text>
      <text class="stat-label">关注</text>
    </view>
  </view>

  <!-- 作品集 -->
  <view class="works-grid">
    <view class="work-item" wx:for="{{works}}" wx:key="id">
      <image src="{{item.cover}}" mode="aspectFill" />
    </view>
  </view>

  <!-- 菜单 -->
  <view class="menu-list">
    <view class="menu-item" bindtap="goSettings">
      <text>设置</text>
      <image src="/icons/arrow-right.png" />
    </view>
    <view class="menu-item" bindtap="goAbout">
      <text>关于</text>
      <image src="/icons/arrow-right.png" />
    </view>
    <view class="menu-item logout" bindtap="logout">
      <text>退出登录</text>
    </view>
  </view>
</view>

<!-- 未登录界面 -->
<view wx:else class="login-prompt">
  <image class="big-avatar" src="/icons/default-avatar.png" />
  <text class="prompt-text">登录后查看更多内容</text>
  <view class="login-btn" bindtap="goLogin">立即登录</view>
</view>
```

## 登录流程

```javascript
goLogin() {
  wx.getUserProfile({
    desc: '用于完善个人资料',
    success: (res) => {
      const userInfo = res.userInfo;
      // 调用后端注册/登录
      wx.request({
        url: 'http://localhost:3000/api/users/login',
        method: 'POST',
        data: { nickname: userInfo.nickName, avatar: userInfo.avatarUrl },
        success: (apiRes) => {
          const fullUserInfo = { ...userInfo, id: apiRes.data.id };
          wx.setStorageSync('userInfo', fullUserInfo);
          this.setData({ isLoggedIn: true, userInfo: fullUserInfo });
          this.loadStats();
        }
      });
    }
  });
}
```

## 退出登录

```javascript
logout() {
  wx.showModal({
    title: '提示',
    content: '确定要退出登录吗？',
    success: (res) => {
      if (res.confirm) {
        wx.removeStorageSync('userInfo');
        this.setData({ isLoggedIn: false, userInfo: null });
      }
    }
  });
}
```

退出登录只需要清除本地存储，不需要调后端接口。下次进入页面时 `onLoad` 检测不到 `userInfo`，自动显示未登录界面。

## 小结

小程序的登录状态管理其实很简单：`Storage` 做持久化，`wx:if` 做视图切换。不需要 Redux，不需要 Context，`Page` 的 `data` 本身就是状态容器。核心原则：数据驱动视图，`setData` 是唯一的状态变更入口。
