# 首页动态发布完整流程

## 从零实现一个发布功能

首页是次元聚的内容中心，核心交互是"发布动态"。这篇文章完整记录从触发发布按钮到内容提交服务器的全流程。

## 第一步：发布按钮

首页右下角固定一个浮动发布按钮，使用渐变背景：

```html
<view class="publish-fab" bindtap="openPublishModal">
  <image src="/icons/plus.png" />
</view>
```

```css
.publish-fab {
  position: fixed;
  right: 32rpx;
  bottom: 120rpx;
  width: 96rpx;
  height: 96rpx;
  border-radius: 50%;
  background: linear-gradient(135deg, #9D7AFF, #7C5CE6);
  box-shadow: 0 8rpx 24rpx rgba(157, 122, 255, 0.4);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 100;
}
```

## 第二步：模态框弹出

点击按钮弹出发布模态框，从底部滑入：

```javascript
openPublishModal() {
  this.setData({ showPublishModal: true });
},

closePublishModal() {
  this.setData({ showPublishModal: false });
}
```

```html
<view class="modal-overlay" wx:if="{{showPublishModal}}" bindtap="closePublishModal">
  <view class="modal-content" catchtap="stopPropagation" animation="{{modalAnimation}}">
    <!-- 标题输入 -->
    <input class="title-input" placeholder="输入标题" value="{{title}}" bindinput="onTitleInput" />

    <!-- 内容输入 -->
    <textarea class="content-input" placeholder="分享你的想法..." value="{{content}}" bindinput="onContentInput" />

    <!-- 图片网格 -->
    <view class="image-grid">
      <view class="image-item" wx:for="{{images}}" wx:key="*this">
        <image src="{{item}}" mode="aspectFill" />
        <view class="remove-btn" bindtap="removeImage" data-index="{{index}}">×</view>
      </view>
      <view class="image-item add-btn" wx:if="{{images.length < 9}}" bindtap="chooseImage">+</view>
    </view>

    <!-- 发布按钮 -->
    <view class="submit-btn" bindtap="submitPost">发布</view>
  </view>
</view>
```

`catchtap` 防止点击模态框内容区时触发外层的关闭事件。

## 第三步：图片上传

调用 `wx.chooseImage`，最多选 9 张减去已选数量：

```javascript
chooseImage() {
  const remaining = 9 - this.data.images.length;
  wx.chooseImage({
    count: remaining,
    sizeType: ['compressed'],
    sourceType: ['album', 'camera'],
    success: (res) => {
      this.setData({
        images: [...this.data.images, ...res.tempFilePaths]
      });
    }
  });
}
```

## 第四步：表单验证

提交前做基本验证：

```javascript
submitPost() {
  if (!this.data.title.trim()) {
    wx.showToast({ title: '请输入标题', icon: 'none' });
    return;
  }
  if (!this.data.content.trim()) {
    wx.showToast({ title: '请输入内容', icon: 'none' });
    return;
  }

  wx.showLoading({ title: '发布中...' });

  wx.request({
    url: 'http://localhost:3000/api/posts',
    method: 'POST',
    data: {
      user_id: getApp().globalData.userId,
      title: this.data.title,
      content: this.data.content,
      images: this.data.images,
      category: this.data.activeCategory
    },
    success: () => {
      wx.hideLoading();
      wx.showToast({ title: '发布成功' });
      this.setData({
        showPublishModal: false,
        title: '',
        content: '',
        images: []
      });
      this.loadPosts(); // 刷新列表
    },
    fail: () => {
      wx.hideLoading();
      wx.showToast({ title: '发布失败', icon: 'none' });
    }
  });
}
```

## 第五步：列表刷新

发布成功后重新请求帖子列表，新发布的帖子出现在列表顶部。

## 完整数据流

```
点击发布 → 弹出模态框 → 输入标题/内容 → 选图/删图 → 表单验证 → API 提交 → 关闭模态框 → 刷新列表
```

整个流程涉及的文件：`home.wxml`（模板）、`home.wxss`（样式）、`home.js`（逻辑），约 400 行代码。

## 小结

发布功能看起来简单，但包含了模态框管理、图片上传、表单验证、API 调用、列表刷新五个子任务。每个子任务都是独立的，做好了拼起来就是完整流程。开发顺序建议：先做 UI 壳子 → 再做图片上传 → 最后接 API。
