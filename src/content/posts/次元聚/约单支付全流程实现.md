# 约单支付全流程实现

## 三步走的支付流程

约单功能不是单个页面，而是一个三步流程：订单详情 → 支付确认 → 支付成功。每一步都是独立页面，通过 `wx.navigateTo` 串联。

## 订单列表页

约单首页显示所有订单，每张卡片展示标题、价格、分类标签和发布者信息：

```html
<view class="order-list">
  <view
    class="order-card"
    wx:for="{{orders}}"
    wx:key="id"
    bindtap="goToDetail"
    data-id="{{item.id}}"
  >
    <view class="order-header">
      <text class="order-title">{{item.title}}</text>
      <text class="order-price">¥{{item.price}}</text>
    </view>
    <text class="order-desc">{{item.description}}</text>
    <view class="order-footer">
      <view class="order-tag">{{item.category}}</view>
      <text class="order-publisher">{{item.publisher_name}}</text>
    </view>
  </view>
</view>
```

## 订单详情页

点击卡片跳转到详情页，URL 带上订单 ID：

```javascript
goToDetail(e) {
  const id = e.currentTarget.dataset.id;
  wx.navigateTo({
    url: `../trading-detail/trading-detail?id=${id}`
  });
}
```

详情页在 `onLoad` 中根据 ID 请求订单数据：

```javascript
onLoad(options) {
  this.setData({ orderId: options.id });
  wx.request({
    url: `http://localhost:3000/api/orders/${options.id}`,
    success: (res) => {
      this.setData({ order: res.data });
    }
  });
}
```

详情页展示发布者卡片（头像、昵称、角色）、需求描述、价格，以及"联系TA"和"接单"两个操作按钮。

## 支付确认页

点击"接单"进入支付页，价格通过 URL 参数传递：

```javascript
goToPayment(e) {
  const { id, price } = e.currentTarget.dataset;
  wx.navigateTo({
    url: `../trading-payment/trading-payment?id=${id}&price=${price}`
  });
}
```

支付页的布局：

```html
<view class="payment-page">
  <!-- 订单摘要 -->
  <view class="order-summary">
    <text class="summary-title">{{order.title}}</text>
    <text class="summary-price">¥{{order.price}}</text>
  </view>

  <!-- 支付方式 -->
  <view class="payment-methods">
    <view
      class="method-item {{selectedMethod === 'wechat' ? 'active' : ''}}"
      bindtap="selectMethod"
      data-method="wechat"
    >
      <image src="/icons/wechat-pay.png" />
      <text>微信支付</text>
    </view>
    <view
      class="method-item {{selectedMethod === 'alipay' ? 'active' : ''}}"
      bindtap="selectMethod"
      data-method="alipay"
    >
      <image src="/icons/alipay.png" />
      <text>支付宝</text>
    </view>
  </view>

  <!-- 协议勾选 -->
  <view class="agreement">
    <checkbox checked="{{agreed}}" bindchange="toggleAgreement" />
    <text>我已阅读并同意《交易服务协议》</text>
  </view>

  <!-- 确认按钮 -->
  <view class="confirm-btn {{agreed ? '' : 'disabled'}}" bindtap="confirmPayment">
    确认支付 ¥{{price}}
  </view>
</view>
```

## 支付成功页

支付确认后跳转到成功页，展示成功动画和后续指引：

```javascript
confirmPayment() {
  if (!this.data.agreed) {
    wx.showToast({ title: '请先同意协议', icon: 'none' });
    return;
  }

  wx.showLoading({ title: '支付中...' });

  wx.request({
    url: 'http://localhost:3000/api/payments',
    method: 'POST',
    data: { order_id: this.data.orderId, method: this.data.selectedMethod },
    success: () => {
      wx.hideLoading();
      wx.redirectTo({
        url: `../trading-success/trading-success?id=${this.data.orderId}`
      });
    }
  });
}
```

成功页用 `wx.redirectTo` 而不是 `navigateTo`，这样用户点返回时直接回到订单列表，不会回到支付页。

成功页包含一个脉冲动画的成功图标和三步指引：

1. 联系发布者确认细节
2. 按约定时间完成服务
3. 双方确认完成交易

## 页面间数据传递策略

| 传递方式 | 使用场景 |
|---------|---------|
| URL 参数 | 订单 ID、价格等简单值 |
| 全局数据 | 用户信息（`getApp().globalData`） |
| 接口请求 | 详细订单数据（详情页自行请求） |

简单数据走 URL 参数，复杂数据走接口请求。这样每个页面都能独立加载数据，不依赖前一个页面的状态。

## 小结

约单流程的核心是"每个页面独立，通过 URL 串联"。详情页自行请求数据，支付页接收价格参数，成功页用 `redirectTo` 防止回退。整个流程约 600 行代码，分三个页面各 200 行，职责清晰。
