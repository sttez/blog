## 二、Skills 技能

Skills 是安装在 `~/.claude/skills/` 目录下的可执行知识模块，通过 `/命令名` 或自动匹配触发。

### 2.1 核心工作流 Skills

#### /brainstorming — 头脑风暴与设计收敛

| 项目 | 说明 |
|------|------|
| **使用范围** | 任何创造性工作：新增功能、构建组件、修改行为、UI 设计 |
| **使用方向** | 在写代码之前，先理解需求、探索方案、收敛设计 |
| **触发方式** | **自动触发** — 在任何实现工作前强制执行 |
| **适用场景** | "添加用户认证"、"做个暗色模式"、"重构这个组件" |

**工作流程：**
1. 探索项目上下文（检查文件、文档、最近提交）
2. 提供视觉伴侣（如涉及 UI）
3. 逐个提出澄清问题
4. 提出 2-3 种方案及取舍分析
5. 呈现设计并获取用户批准
6. 写入设计文档 `docs/superpowers/specs/`
7. 自检 → 用户审查 → 过渡到实现

**铁律：** 在设计获批前，绝不能写任何代码。

---

#### /karpathy-guidelines — 编码行为准则

| 项目 | 说明 |
|------|------|
| **使用范围** | 编写、审查或重构代码的任何场景 |
| **使用方向** | 防止 LLM 常见编码错误 |
| **触发方式** | 自动应用于所有编码工作 |

**四条核心原则：**
1. **先思考再编码** — 明确假设，不确定就问
2. **简洁优先** — 最少代码解决问题，不做超出需求的功能
3. **精准改动** — 只碰必须改的，不"改善"无关代码
4. **目标驱动** — 定义成功标准，循环直到验证通过

### 2.2 前端与设计 Skills

#### /frontend-design — 前端设计

| 项目 | 说明 |
|------|------|
| **使用范围** | 构建网页组件、页面、应用或任何前端界面 |
| **使用方向** | 创建有设计品质、非"AI 味"的前端代码 |
| **触发方式** | 用户要求构建 UI 组件或页面时自动触发 |

**设计原则：**
- 明确的美学方向（极简/极繁/复古/有机/奢华等）
- 独特的字体搭配（避免 Inter、Roboto 等通用字体）
- 有主次的色彩体系（60-70% 主色 + 1-2 辅色 + 1 强调色）
- 动效与微交互（优先 CSS-only 方案）
- 非常规的空间构成（不对称、重叠、打破网格）

**适用场景：** 网站、落地页、仪表盘、React/Vue/HTML 组件

### 2.3 知识图谱 Skills

#### /graphify — 知识图谱构建与查询

| 项目 | 说明 |
|------|------|
| **使用范围** | 代码库、文档、论文、图片、视频的分析与关联 |
| **使用方向** | 构建可导航的知识图谱，发现跨文件/跨文档的隐藏关系 |
| **触发方式** | `/graphify` 或用户询问代码库问题时自动建议 |
| **存储位置** | `graphify-out/` 目录 |

**常用命令：**
```bash
/graphify                          # 对当前目录构建完整图谱
/graphify <path>                   # 对指定路径构建
/graphify https://github.com/...   # 克隆仓库后构建
/graphify <path> --update          # 增量更新（仅处理变更文件）
/graphify <path> --wiki            # 构建 Agent 可爬取的 Wiki
/graphify query "问题"             # BFS 遍历问答
/graphify path "模块A" "模块B"     # 概念间最短路径
/graphify explain "概念"           # 概念的通俗解释
```

**输出产物：**
- `graphify-out/GRAPH_REPORT.md` — 人类可读的报告（God Nodes、社区、知识缺口）
- `graphify-out/graph.json` — GraphRAG 可用的图数据
- `graphify-out/index.html` — 交互式可视化

**当前项目图谱快照：** 996 节点 / 1854 边 / 62 社区，97% EXTRACTED，3% INFERRED。

## 三、Gstack 工具栈

Gstack 是一个集成的 AI 开发工具栈，提供浏览器自动化、QA 测试、设计审查、部署管理等 33 个子技能。安装路径：`~/.claude/skills/gstack/`。

**CLAUDE.md 强制规则：** 所有网页浏览必须使用 `/browse`，**禁止** 使用 `mcp__claude-in-chrome__*` 工具。

## 六、Hooks 钩子

Hooks 在特定工具调用前后自动执行，为 Claude Code 添加上下文提醒。

### PreToolUse 钩子（工具调用前）

| 匹配工具 | 行为 |
|---------|------|
| `Grep` | 检查 `graphify-out/GRAPH_REPORT.md` 是否存在，存在则提醒：优先使用知识图谱而非 grep |
| `Glob` | 同上 |
| `Bash`（含 grep/rg/find/fd 等搜索命令） | 同上 |

**效果：** 当项目中存在知识图谱时，搜索操作会自动附加上下文提醒，引导 Claude 优先使用 `graphify query`、`graphify path` 等图谱遍历工具，而不是原始文件扫描。
