# 三种部署方案对比：裸机、宝塔、Docker

## 方案总览

ARCH ACG 提供了三种部署方式，覆盖不同技术水平的用户：

| 方案 | 适合人群 | 优点 | 缺点 |
|------|---------|------|------|
| 裸机部署 | 熟悉 Linux | 完全掌控、性能最优 | 步骤多、环境管理麻烦 |
| 宝塔面板 | 不熟悉命令行 | 图形化操作、一键安装 | 额外资源占用、依赖宝塔 |
| Docker Compose | 想要一致环境 | 一键启动、环境隔离 | 需要学 Docker |

## 方案一：裸机部署

### 环境准备

```bash
# Java 21
sudo apt install openjdk-21-jdk

# MySQL 8
sudo apt install mysql-server
mysql -u root -p -e "CREATE DATABASE arch_acg CHARACTER SET utf8mb4;"

# Redis 7
sudo apt install redis-server

# Node.js 20（前端构建）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs
```

### 构建和启动

```bash
# 后端
cd arch-acg-backend
mvn clean package -DskipTests
java -jar target/arch-acg-backend-1.0.0.jar &

# 前端
cd arch-acg-home
npm install && npm run build
# 把 dist/ 目录放到 Nginx 的 webroot 下
```

### Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端 SPA
    location / {
        root /var/www/arch-acg;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://localhost:8080;
    }

    # WebSocket
    location /ws/ {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 方案二：宝塔面板

宝塔用户只需在面板里点点鼠标：

1. 安装 Java 项目管理器 → 选 JDK 21
2. 安装 MySQL → 创建数据库 → 导入 SQL
3. 安装 Redis → 一键启动
4. 添加 Java 项目 → 选择 jar 包 → 启动
5. 添加网站 → 配置反向代理

适合不习惯命令行的用户。

## 方案三：Docker Compose（推荐）

最省心的方式，一条命令搞定全栈：

```yaml
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_DATABASE: arch_acg
    volumes:
      - mysql-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping"]
      interval: 10s

  redis:
    image: redis:7-alpine
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]

  backend:
    build: ./arch-acg-backend
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_healthy
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/arch_acg
      JWT_SECRET: ${JWT_SECRET}

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
      - ./arch-acg-home/dist:/usr/share/nginx/html
    depends_on:
      - backend
```

```bash
# 启动
docker compose up -d

# 查看日志
docker compose logs -f backend
```

## 常见问题

| 问题 | 解决 |
|------|------|
| 启动报 JWT_SECRET 为空 | 检查环境变量是否配置 |
| 前端白屏 | 检查 Nginx 的 try_files 配置 |
| WebSocket 连不上 | 确认 Nginx 配了 Upgrade 头 |
| 401 一直弹 | Token 过期，清 localStorage 重新登录 |

## 小结

个人开发推荐裸机或 Docker。宝塔适合想快速上线且不熟悉 Linux 的用户。Docker Compose 是生产环境的最优选择——环境一致、一键启动、方便扩展。不管哪种方案，关键是 Nginx 配置要对：SPA 路由 fallback、API 代理、WebSocket Upgrade，这三个配对了就基本没问题。
