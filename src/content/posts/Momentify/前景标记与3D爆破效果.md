# 前景标记与 3D 爆破效果实现

## 效果说明

3D 爆破模板的视觉核心是：图片中的主体"突破"九宫格的边界线，产生立体感。实现思路是**前景/背景分离**——用户标注哪些区域是前景，渲染时前景层叠在九宫格线之上。

## 标记页面

MarkerPage 提供一个画布，用户用两种颜色的画笔标注：

- **绿色**：前景区域（要突破边界的部分）
- **红色**：背景区域（被边界线切割的部分）

```dart
class _StrokePainter extends CustomPainter {
  final List<Stroke> strokes;

  @override
  void paint(Canvas canvas, Size size) {
    for (final stroke in strokes) {
      final paint = Paint()
        ..color = stroke.isForeground
            ? Colors.green.withOpacity(0.5)
            : Colors.red.withOpacity(0.5)
        ..style = PaintingStyle.stroke
        ..strokeWidth = stroke.width
        ..strokeCap = StrokeCap.round;

      final path = Path();
      for (int i = 0; i < stroke.points.length; i++) {
        if (i == 0) {
          path.moveTo(stroke.points[i].dx, stroke.points[i].dy);
        } else {
          path.lineTo(stroke.points[i].dx, stroke.points[i].dy);
        }
      }
      canvas.drawPath(path, paint);
    }
  }
}
```

## 生成蒙版

用户标记完成后，通过 `RepaintBoundary` 截取标记画布为 PNG 图片，存入 `foregroundMaskProvider`：

```dart
final boundary = _repaintKey.currentContext!
    .findRenderObject() as RenderRepaintBoundary;
final image = await boundary.toImage();
final byteData = await image.toByteData(format: ImageByteFormat.png);
ref.read(foregroundMaskProvider.notifier).state =
    byteData!.buffer.asUint8List();
```

## 渲染时的分层

CanvasComposer 在渲染 3D 模板时使用三层叠加：

```
底层：原图（带九宫格线）
中层：前景蒙版中被标记为前景的区域，放大一定比例
顶层：九宫格线（前景区域不绘制）
```

绿色标记区域对应的像素在中层渲染，由于放大了，它们会"溢出"九宫格边界线，产生突破的立体感。

## 交互优化

画笔支持 3 档粗细调节。大范围区域用粗笔快速涂抹，细节部分用细笔精确标注。另外提供"清除重来"按钮，因为第一次标记通常不够精确。
