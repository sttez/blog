# 九宫格切图与高清导出指南

## 朋友圈九宫格需求

朋友圈一次最多发 9 张图，九宫格玩法是把一张大图切成 3×3 的 9 块，按顺序发出去。Momentify 需要支持预览九宫格效果，并导出 9 张独立图片。

## Widget 截图为图片

核心 API 是 `RenderRepaintBoundary.toImage()`：

```dart
final boundary = _repaintKey.currentContext!
    .findRenderObject() as RenderRepaintBoundary;
final image = await boundary.toImage(pixelRatio: 2.0);
final byteData = await image.toByteData(format: ImageByteFormat.png);
final pngBytes = byteData!.buffer.asUint8List();
```

`pixelRatio: 2.0` 表示用 2 倍设备像素渲染，保证在 Retina 屏上导出的图片不会模糊。

## 九宫格切割

拿到整张图片后，用 `ui.PictureRecorder` 把它切成 9 块：

```dart
List<Uint8List> splitNineGrid(ui.Image source) {
  final cellWidth = source.width ~/ 3;
  final cellHeight = source.height ~/ 3;
  final results = <Uint8List>[];

  for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 3; col++) {
      final recorder = ui.PictureRecorder();
      final canvas = Canvas(recorder);

      canvas.drawImageRect(
        source,
        Rect.fromLTWH(
          col * cellWidth.toDouble(),
          row * cellHeight.toDouble(),
          cellWidth.toDouble(),
          cellHeight.toDouble(),
        ),
        Rect.fromLTWH(0, 0, cellWidth.toDouble(), cellHeight.toDouble()),
        Paint(),
      );

      final picture = recorder.endRecording();
      final cellImage = picture.toImageSync(cellWidth, cellHeight);
      final byteData = cellImage.toByteDataSync(format: ImageByteFormat.png);
      results.add(byteData!.buffer.asUint8List());
    }
  }
  return results;
}
```

## 保存到相册

用 `image_gallery_saver` 把 PNG 字节写入系统相册：

```dart
for (int i = 0; i < cells.length; i++) {
  await ImageGallerySaver.saveImage(cells[i], name: 'momentify_grid_$i');
}
```

## 导出页交互

ExportPage 支持在整图预览和九宫格预览之间切换。整图用 `Image.memory()` 直接显示导出的 PNG，九宫格用 3×3 的 GridView 展示 9 个切割后的图片，用户可以确认切割效果再保存。

保存按钮有 loading 动画和成功反馈——用 `ScaleTransition` + `elasticOut` 曲线做一个弹性缩放效果。
