# 贴纸与文字覆盖层系统

## 数据模型

贴纸和文字在数据层面都是"覆盖层"，共享相同的定位逻辑：

```dart
class TextOverlay {
  final String id;
  final String text;
  final Offset position;
  final double fontSize;
  final Color color;
  final bool isBold;
}

class StickerOverlay {
  final String id;
  final String emoji;
  final Offset position;
  final double scale;
}
```

## 贴纸选择器

底部弹出的 `StickerSelector` 是一个 8 列的 GridView，展示 48 个 emoji 贴纸，分为四组：

- 心形与符号：❤️💛💚💙💜🖤🤍💔❣️💕💞💓💗💖💘💝
- 箭头与标志：➡️⬅️⬆️⬇️↩️↪️⤴️⤵️🔃🔄🔙🔚🔛🔜🔝
- 食物：🍎🍊🍋🍇🍉🍓🍒🍑🥝🥑🍔🍕
- 旅行与自然：🌸🌺🌻🌹🌷🌈⭐🌙☀️🌊🏔️🏖️

选中贴纸后在画布上创建一个 `StickerOverlay`，位置居中，用户可以拖拽移动。

## 文字编辑器

`TextEditor` 包含三个控制区域：

1. **输入框**：TextField 输入文字内容
2. **字号滑块**：Slider 控制 12-48 的字号范围
3. **颜色选择**：8 个颜色圆点，点击选中
4. **加粗按钮**：切换 bold 样式

## 拖拽实现

覆盖层用 `Positioned` + `GestureDetector` 实现拖拽：

```dart
Positioned(
  left: overlay.position.dx,
  top: overlay.position.dy,
  child: GestureDetector(
    onPanUpdate: (details) {
      setState(() {
        overlay = overlay.copyWith(
          position: overlay.position + details.delta,
        );
      });
    },
    child: Text(
      overlay.text,
      style: TextStyle(
        fontSize: overlay.fontSize,
        color: overlay.color,
        fontWeight: overlay.isBold ? FontWeight.bold : FontWeight.normal,
      ),
    ),
  ),
)
```

贴纸的拖拽类似，但额外支持 `onScaleUpdate` 来处理缩放手势。

## 删除覆盖层

长按覆盖层弹出删除确认。当前实现是简单的 AlertDialog，后续可以优化为拖拽到垃圾桶图标上删除，交互更直观。
