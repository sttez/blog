# 撕纸效果与纤维纹理的实现

## 效果概述

撕纸模板在图片上叠加一个不规则遮罩，模拟从中间撕开的效果。支持四个方向：上撕、下撕、左撕、中心撕裂。

## 不规则边缘

撕纸边缘不能是直线——真实撕开的纸是不规则的。用 60 个路径点生成边缘，每个点叠加**随机噪声 + 正弦波**：

```dart
for (int i = 0; i <= 60; i++) {
  final t = i / 60;
  final noise = (random.nextDouble() - 0.5) * 0.06;
  final wave = sin(i * 0.3) * 0.03;
  final y = baseLine + (noise + wave) * canvasHeight;
  path.lineTo(t * canvasWidth, y);
}
```

随机噪声给出宏观的不规则性，正弦波给出微观的起伏感。两者叠加后边缘看起来就像真的撕开一样。

## 纤维纹理

纸张撕开后边缘会有纤维丝翘起来。`TearMaskPainter._drawFibers` 沿着撕纸路径绘制短小的纤维线：

```dart
void _drawFibers(Canvas canvas, Path tearPath, Random random) {
  final metrics = tearPath.computeMetrics();
  for (final metric in metrics) {
    for (int i = 0; i < fiberCount; i++) {
      final t = random.nextDouble();
      final tangent = metric.getTangentForOffset(metric.length * t);
      if (tangent == null) continue;

      final pos = tangent.position;
      final fiberLength = random.nextDouble() * 6 + 2;
      final fiberAngle = tangent.angle + (random.nextDouble() - 0.5) * 1.2;

      final fiberEnd = Offset(
        pos.dx + cos(fiberAngle) * fiberLength,
        pos.dy + sin(fiberAngle) * fiberLength,
      );
      canvas.drawLine(pos, fiberEnd, fiberPaint);
    }
  }
}
```

关键 API 是 `Path.computeMetrics()` 和 `getTangentForOffset()`。前者把路径分解成度量段，后者在任意位置获取切线方向——纤维线沿着切线方向延伸一小段，方向随机偏转，效果非常自然。

## 遮罩实现

实际渲染时，用 `Path` 定义图片的可见区域，撕纸边缘以上的区域显示图片，以下的区域透明：

```dart
final clipPath = Path();
// 根据方向构建不同的裁剪路径
switch (direction) {
  case TearDirection.top:
    clipPath.addRect(Rect.fromLTRB(0, tearY, width, height));
  case TearDirection.bottom:
    clipPath.addRect(Rect.fromLTRB(0, 0, width, tearY));
  // ...
}
canvas.clipPath(clipPath);
```

四个方向的模板只是改变了裁剪区域的范围，纤维纹理的绘制逻辑完全复用。
