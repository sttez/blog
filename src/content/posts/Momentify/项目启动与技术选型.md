# Momentify 项目启动与技术选型

## 做什么

Momentify 是一个朋友圈图片美化工具。用户选模板、选照片、编辑导出，最终发一条好看的朋友圈。核心需求是**模板丰富、操作简单、导出高清**。

七类模板覆盖了主流的朋友圈玩法：拼图、装饰边框、故事卡片、笔记卡片、3D 爆破、撕纸、碎裂效果。每类模板都是一个视觉风格，用户只需要往里填图就行。

## 为什么选 Flutter

对比了 React Native 和原生开发后，选 Flutter 的理由很简单：

- **CustomPainter 能力强**：裂纹、撕纸、3D 分割这些效果都需要自定义绘制，Flutter 的 Canvas API 比 RN 的底层能力强得多
- **RepaintBoundary 导出**：可以直接把 Widget 树渲染成高清图片，不需要额外的图片处理库
- **单代码库**：iOS 和 Android 共用一套代码，开发效率高

## 技术栈

| 模块 | 选择 | 理由 |
|------|------|------|
| 状态管理 | flutter_riverpod | 页面间需要共享图片、模板、导出结果，StateProvider 够用 |
| 路由 | go_router | StatefulShellRoute 支持底部导航栏 + 嵌套路由 |
| 图片选择 | image_picker | 官方维护，支持多选 |
| 图片导出 | image_gallery_saver | 写入系统相册 |
| 本地存储 | hive | 轻量 KV 存储，后续存模板和作品数据 |
| 字体 | google_fonts | 按需加载字体，不需要预装 |

## 项目结构

按功能模块划分，而不是按层级划分：

```
lib/
├── core/           # 颜色、主题、路由、通用组件
├── data/
│   ├── models/     # 数据模型（模板、覆盖层、滤镜、裂纹配置）
│   └── repositories/  # 模板数据源
└── features/
    ├── home/       # 模板库首页
    ├── picker/     # 图片选择
    ├── editor/     # 编辑器（画布 + 工具栏）
    ├── marker/     # 前景标记（3D 效果用）
    └── export/     # 导出预览
```

## 下一步

技术选型确定后，下一步是实现模板系统——这是整个项目的数据骨架。所有页面的 UI 和交互都依赖模板定义的布局槽位。
